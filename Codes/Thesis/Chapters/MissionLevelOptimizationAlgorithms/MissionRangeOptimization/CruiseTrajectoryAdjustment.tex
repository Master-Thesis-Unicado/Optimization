When adjusting cruise distance, the existing cruise trajectory must be extended or truncated to match the new distance requirement. For distance extension, a new cruise segment is simulated starting from the terminal state of the existing cruise trajectory, continuing the level flight simulation until the additional distance is covered.

For distance truncation, the cruise trajectory is cut at the point where the target distance is reached. If the target distance falls between trajectory points, linear interpolation is applied to determine the state at the exact target distance, ensuring accurate distance matching.
