Longitudinal trim requires satisfaction of force equilibrium in the vertical direction and moment equilibrium about the center of gravity. The condition $L = W$ establishes the required lift coefficient:

\begin{equation}
C_L = \frac{W}{qS} = \frac{mg}{\frac{1}{2}\rho V^2 S}
\end{equation}

The trim analysis is carried out with the UNICADO aerodynamics library dynamically at each time step, which provides the trimmed flight state for the current operating conditions.
