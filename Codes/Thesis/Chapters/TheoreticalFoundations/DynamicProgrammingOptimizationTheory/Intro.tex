This chapter sets out the basis for using dynamic programming in the trajectory optimization problem. The presentation goes from the core principles to the elements needed for the implementation. It starts with Bellman’s principle of optimality and the discrete state-space formulation. The classical two-dimensional setup is then expanded to three dimensions by adding the throttle lever position as an explicit control variable. With this addition, altitude, mach number, and throttle lever position can be optimized within the same framework.
