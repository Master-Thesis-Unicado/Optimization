Terminal constraints define acceptable conditions at phase transitions and mission completion. Climb termination requires reaching cruise altitude with Mach number within tolerance: $|M_{climb,final} - M_{target}| < \epsilon_M$, where $\epsilon_M = 0.010$ provides 1\% Mach accuracy.

The terminal constraint enforcement occurs through two distinct mechanisms: soft guidance during optimization (through penalty system) and hard constraint enforcement during post-processing (through terminal state selection). The dynamic programming algorithm applies Mach trajectory guidance penalties during the forward pass to influence the trajectory path toward the target Mach number. However, the terminal Mach constraint is enforced independently as a hard constraint after the forward pass completes. The hard constraint mechanism identifies all terminal Mach states within tolerance of the target and masks all other states by setting their cost-to-go values to infinity. The optimal terminal state is then selected as the state with minimum cost-to-go among the valid terminal states. This hard constraint enforcement ensures that the terminal Mach number always satisfies the tolerance requirement, regardless of whether the guidance penalty system is enabled or disabled. When guidance is disabled, the optimizer minimizes fuel consumption without trajectory guidance during the forward pass, but the terminal constraint still enforces the target Mach requirement through the hard constraint mechanism. Consequently, the terminal Mach number may be identical whether guidance is enabled or disabled, as the hard constraint selects from the same set of valid terminal states. The guidance system primarily affects the trajectory path and fuel consumption, while the terminal constraint determines the final Mach selection.

Descent terminal conditions require reaching approach altitude with appropriate speed for approach configuration. The target Mach number $M_{approach} = 0.25$ corresponds to typical approach speeds, while the altitude $h_{approach} = 300$ m represents standard approach initiation height. Terminal constraint satisfaction validates optimization accuracy and ensures operational viability of computed trajectories.
